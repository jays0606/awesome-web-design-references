# Contributing

Open an issue or pull request with:
- Original public URL and a short reason this reference adds something distinct.
- Suggested category and the specific principle a builder could adapt.
- Capture date, viewport, locale, and any overlays or loading limitations.
- One concise observation and one caution; avoid unsupported performance or conversion claims.

Only capture public marketing pages. Stop if navigation lands on a signed-in dashboard, private content, or an access challenge. Never include account information, browser chrome with personal data, or third-party assets presented as reusable templates.

Prefer a small number of useful, reviewed captures to unreviewed bulk screenshots. Keep the source URL and attribution attached. Run python3 tools/build.py after changing REFERENCES.json to update the gallery and skill catalog. Request corrections or removal through repository issues.
